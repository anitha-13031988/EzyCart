
# EzyCart 🛒

**EzyCart** is a simple e-commerce website built with **React Hooks**, **HTML**, and **CSS**.  
It allows users to view products and add them to the cart — a beginner-friendly project showcasing state management in React.

---

## 🔧 Technologies Used

- React JS (with Hooks)
- HTML & CSS
- JavaScript

---

## 📦 Features

- Product listing with name and price
- Add-to-cart functionality
- View cart contents dynamically
- Clean and responsive layout
